\chapter{Conclusion}
This report presented the design and formalization of a structured framework for mission-driven ROS configuration, integrating semantic interpretation with deterministic system synthesis. The work addressed the limitations of manual and static configuration processes in ROS-based robotic systems, where small changes in mission objectives often require extensive modifications across parameter files and launch scripts.

The proposed architecture separates concerns into clearly defined layers: natural-language mission interpretation, schema validation, deterministic capability realization, ROS orchestration, evidence-backed parameter retrieval, parameter selection and value reasoning, configuration-plan construction, and launch-graph generation. By combining language models for high-level semantic abstraction with deterministic algorithms for structural validation and configuration materialization, the framework preserves both flexibility and reproducibility.

A key contribution is the explicit representation of repository facts and robot-specific design knowledge. Static extraction and integration preserve deployment, parameter, interface, and provenance information; capability realization resolves dependencies and implementation conflicts; and a complete physical configuration model separates 109 writable locations from 114 effective parameter occurrences. The language model is restricted to validated structured conclusions, while deterministic templates retain control of syntax, file placement, and unchanged baseline values.

The experimental results also identify the current limiting factor. On 150 generated mission paraphrases, the initial baseline achieved 76.1\% capability micro $F_1$ but only 1.6\% parameter-selection micro $F_1$, with no jointly exact mission. Few-shot examples increased outcome accuracy from 63.3\% to 90.7\% and parameter-selection micro $F_1$ to 11.8\%, but exact selection remained 0.7\% and validated completion decreased. The framework therefore succeeds at exposing and containing model errors, but the present model and retrieval-to-selection interface are not yet sufficiently accurate for autonomous deployment.

The appropriate conclusion is consequently narrower than claiming complete natural-language control of the robot. The work establishes a reproducible architecture and evaluation boundary for source-grounded ROS configuration, demonstrates partial semantic capability, and provides auditable failure evidence. Independent dataset review, unsupported and ambiguous cases, controlled context ablations, oracle value experiments, repeated runs, and simulation or hardware validation remain necessary before operational reliability can be claimed.
