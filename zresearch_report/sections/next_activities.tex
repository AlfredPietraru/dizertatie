\chapter{Next-Semester Activities}
The first semester of this project focused on establishing the conceptual and architectural foundation of the proposed system through a state-of-the-art analysis and formal system design. This phase included a literature review on ROS orchestration frameworks, YAML automation approaches, container-based deployment strategies, and LLM code synthesis methods. Comparative analysis tables were developed to identify the limitations of existing tools and to position the proposed framework within the broader research landscape.

A layered system architecture was designed, clearly defining the data flow between mission interpretation, component resolution, configuration synthesis, and launch generation modules. The mission interpretation schema, component database model, and constraint satisfaction strategy for component selection were formally specified. Particular attention was given to separating semantic interpretation from deterministic configuration synthesis in order to ensure structural validity and reproducibility.
The planned activities are as follows:

\begin{itemize}
    \item Dvelopment of a reusable Jinja2-based templating engine for parameterized ROS configuration files
    \item Define a set of 10--15 representative missions derived from AntRobot's operational modes, covering scenarios such as SLAM exploration, localization-only navigation, mapping with LiDAR, RGB-D-based mapping, and navigation with obstacle avoidance.
    
    \item Generate paraphrased mission descriptions using instruction-tuned models (e.g., Mistral or DeepSeek) in order to expand the dataset to approximately 100 mission variants. These missions will be paired with their corresponding validated configuration outputs and stored in a structured JSONL format.
    
    \item Implement an inference pipeline using the Hugging Face Transformers framework to convert natural-language mission descriptions into structured JSON representations
    
    \item Experiment with prompt engineering strategies (zero-shot and few-shot prompting) to enforce strict schema adherence before considering any model fine-tuning techniques.
    
    \item Connect the validated JSON outputs to the existing component resolution and templating system to enable complete end-to-end configuration generation.
    
    \item Validate generated configurations in simulation and, where feasible, on the physical AntRobot platform to ensure structural correctness and reproducibility.
\end{itemize}

By the end of the second semester, the expected outcomes include a synthetic mission configuration dataset, an LLM-assisted mission interpretation module, and a fully integrated prototype capable of transforming natural-language instructions into executable ROS deployments. This phase will complete the transition from a deterministic configuration framework to a hybrid semantic-to-execution orchestration system.
